# PlanMate – Smart Task Management System

PlanMate is a full-stack task management application designed to help users organize, manage, and track their daily tasks efficiently.

The application provides task management, scheduling, notifications, calendar visualization, analytics, and AI-powered assistance.

## 🚀 Features

- User Registration and Login
- Create, update, delete, and manage tasks
- task list
- Search and filter tasks
- Calendar-based task visualization
- task and reminders
- Task analytics
- AI-powered task assistance
- Export/download task information
